# Правила проекта

## Подтверждение фактов о технологиях

Перед любым ответом, советом или изменением кода, который касается технологий,
библиотек, API, фреймворков, инструментов, методик и практик:

1. **Context7** — для библиотек, фреймворков и их API: сначала
   `resolve-library-id`, затем `query-docs`. Версию и сигнатуры смотреть там,
   а не по памяти модели.
2. **Интернет** — для методик, стандартов, сравнений и практик: поиск
   (TinyFish `search`/`fetch_content`) и минимум один независимый источник.
3. Если источники расходятся — сказать об этом прямо.
4. Не выдумывать API, параметры, цифры и названия. Если подтверждения нет —
   написать «не подтверждено» вместо догадки.
5. В ответе давать ссылку на источник, если утверждение не тривиально.

Тривиальное (синтаксис языка, школьная математика, содержимое открытого файла)
проверки не требует.
